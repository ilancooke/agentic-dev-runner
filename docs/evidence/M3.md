Committed approval tests retain base64 bytes and blob OIDs for the roadmap and
linked requirements. Ignored uncommitted requirements cannot be authorized. Python
and npm/Node fixtures (including a `trunk` default branch) use the same state contract.
Source/configuration hashes are retained and rechecked, and model/effort downgrades
are rejected rather than selected as fallback.

The termination checkpoints exercised by both error and process-exit tests are:
`journal.opened`, `journal.written`, `journal.file_synced`,
`journal.directory_synced`, `atomic.opened`, `atomic.written`,
`atomic.file_synced`, `atomic.replaced`, and `atomic.directory_synced`.
Workers exit through `os._exit(72)` without Python cleanup; parent recovery obtains
fresh locks. These are local process interruption tests, not host power-loss tests.

## Limits and next work

[STATE.md](../STATE.md) defines the exact approval exceptions, identity/versioning,
phase/intent table, append/replace protocol, limits and safe recovery instructions.
This is a trusted-library foundation; operational CLI/service wiring remains M9.
No operational namespace was created. No real agent, GitHub, Docker, AWS, service,
deployment, SIGKILL, VM reboot or storage power-loss experiment ran.

Directory locks require Linux/POSIX cooperating processes/local filesystem semantics.
They are not a boundary against hostile code/admin writers or concurrent mount/path
replacement. Hash chains are corruption checks, not signatures. M4 must enforce
execution/credential/network/container boundaries; M5/M6 must add verified publication
states and effect-specific reconciliation with an explicit schema evolution decision.

Approval uses a conservative supported Markdown link closure and byte protection.
External links/assets are refused until captured locally, ancestor instructions are
separate uncommitted attestations, and natural-language consistency still needs review.
Renewal currently requires a clean default-branch checkout. No automatic repair,
history truncation, migration, archival or completed-run advancement exists. Journal,
event and approval size limits stop rather than silently dropping evidence. Requested
GPT-6.1-Sol/high remains a label pending M4 CLI/capability verification.
